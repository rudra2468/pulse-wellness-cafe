# Host PULSE for free on GitHub Pages

1. Create a free account at github.com (skip if you have one).
2. Click New repository. Name it `pulse-wellness-cafe`, set it to Public, click Create.
3. Click "uploading an existing file". Drag in everything from this folder: `index.html`, the `assets` folder and `.nojekyll`. Click Commit changes.
4. Go to Settings, then Pages. Under Build and deployment choose Source: Deploy from a branch, Branch: main, folder: / (root). Click Save.
5. Wait about a minute. Your site is live at https://YOUR-USERNAME.github.io/pulse-wellness-cafe/

Updating later: open the repo, click Add file, Upload files, drop the new version, commit. The site refreshes in a minute.

Alternative with no account setup: drag this folder onto https://app.netlify.com/drop for an instant free link.
